# V992.56 reference screenshots — Samsung S90C

Digitally acquired from the owner's existing V992.56 installation on Samsung S90C (QE65S90CATXZT), 24 October 2026. Each original PNG is 1920 × 1080 and is published unchanged.

These images document the working reference UX being ported. They are **not screenshots of the proposed upstream branch** and do not certify its TV behavior. The reference also includes optional Rectangle artwork, clock, weather wallpaper and source-dock contributions beyond the scope of PR #26. Italian labels reflect the TV's selected locale.

![Home tile actions](https://github.com/user-attachments/assets/8e5bd1db-df49-4729-bf50-cdc7720fb296)
